## Design Principles

**Academic Focus**:
- All features are design-documented first (spec → plan → tasks)
- No implementation without complete design artifacts
- Reusable patterns extracted for future projects

**Privacy First**:
- Anonymous-by-default architecture
- Explicit opt-in for personalization
- Regulatory compliance (GDPR, CCPA, FERPA)

**Educational Alignment**:
- Features support learning goals, never distract
- Gamification is transparent and opt-in
- Accessibility maintained (WCAG 2.1 AA)
